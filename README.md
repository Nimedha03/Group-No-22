# DOCSHARE — BICT Student Resource Hub
DOCSHARE is a centralized digital repository designed for Department of ICT (BICT) students. It aggregates lecture notes, tutorials, and past papers into a single, organized platform so students don't have to search through fragmented group chats or drives.

## Project Theme & Vision

* **The Problem:** Academic materials (notes, past papers, tutorials) are scattered across multiple platforms, leading to duplicated effort and lost files between batches.
* **The Solution:** A unified platform where students can easily upload, organize, search, and browse academic resources by course code, keyword, or file type.
* **Target Audience:**
* **Student Contributors & Class Monitors:** Upload and organize resources for current and upcoming batches.
* **Lecturers & Instructors:** Share reference materials without administrative overhead.

## Tech Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript, Bootstrap 5, FontAwesome / Lucide Icons
* **Backend:** PHP 8
* **Database:** MySQL (XAMPP)
* **Version Control:** Git & GitHub
